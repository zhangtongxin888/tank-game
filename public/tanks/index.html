Quick start

How class upgrades work.

From one turret to a war machine — the verified shape of the system.

Everyone starts equal

You spawn as a small circular tank with a single turret. Early levels come from shooting food shapes, not from fighting.

Press Q when an upgrade unlocks

The tank upgrade menu (Q) is where class evolutions happen. Later upgrades can add turrets or change your shots entirely — guides mention flame and freeze variants among the possibilities.

Consult the in-game Index

The game includes an Index that shows tank build paths. Paths can lock each other out, so read the Index before committing a branch — not after.

Match the class to your stats

A class is only half the build. Ranged and melee tanks want different stat priorities — pair your Q choices with the spending plan on the stats page.

Honest policy

Why there is no tank tree here.

A wrong tree is worse than no tree. Here is what we verified on August 20, 2026.

Community tables are incomplete or contested. Reader comments on the big secondary tank tables already dispute listed paths, and version 2.4's rebalance may have shifted older recommendations.

Even the big guides gave up: one major outlet removed its own path tables because the game now includes an Index that shows build paths directly.

So the rule is simple: the in-game Index is the only build-path source this site endorses. It updates with the game; no blog does.

Community wikis are unofficial. Treat fan wikis as player notes, never as the developer handbook — the in-game menu wins every disagreement.

PVP reality

Frontal barrels win duels.

The most useful class advice from current guides — and it is about barrels, not names.

🎯

For fighting: frontal barrels

Tanks whose firepower points forward are the reliable PVP choice because all of their DPS can be aimed at the duel in front of you.

🌾

For farming: omnidirectional

Side- and rear-barrel tanks farm dense mid-map food well, but that spread damage cannot be aimed — expect to lose straight 1v1s with them.

Extra places exist: trackers list sister places such as STARTER, PRO, MEGA, TRADING, and Red VS Blue alongside the main arena. Their exact matchmaking rules were not verified in-game — stick to the main place until you know what each one is (checked August 20, 2026).

Tanks FAQ

Before you press Q.

The questions that decide whether your next life has a plan.

How many tanks are there?

The official description says over 150 unique tanks to unlock. Nobody has a verified public tree of all of them — use the in-game Index.

When do I get my first class upgrade?

Open the Q menu as you level and it will show you. Exact unlock levels vary by path and can shift with rebalances, so the menu — not a dated table — is the reference.

Can a class choice be a mistake?

Paths can lock each other out, which is why the Index exists. Read where a branch leads before you commit, especially once you have a stat plan from the stats page.

Are there group-exclusive or shop tanks?

Guides report group perks for 7x3 members and shop unlocks, but specifics are unverified and change with updates. Check the group page and in-game shop on the day you play.

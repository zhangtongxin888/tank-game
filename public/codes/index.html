Redeem safely

Four steps — from the lobby.

Multiple guides confirm the same left-side codes control. One warning matters more than the rest.

Get to safety first

The game does not pause while the codes menu is open. Unless you are in the lobby, other tanks can still shoot you mid-typing — redeem before you drop into the arena.

Open the blue tick on the left

Look for the blue tick / checkmark icon on the left side of the screen, reported under the Buffs area, and press it to open the codes menu.

Enter the code exactly

Type or paste into the code field and press Redeem. Near-miss strings fail — one expired listing famously missed a single final letter — so copy-paste beats typing from memory.

Confirm the reward landed

Watch for the XP or gem credit. If a code fails even when pasted exactly, it has expired since our November 5, 2026 check — check the official page or Discord for a replacement.

Codes FAQ

When a code will not work.

The usual culprits, in order of likelihood.

Why did my code fail?

Check for typos first — even a single missing letter fails. If the paste is exact, the code has likely expired since October 28, 2026. And never redeem mid-arena: the game does not pause, so you may have died before confirming.

Where exactly is the codes button?

A blue tick / checkmark on the left side of the screen, reported beneath the Buffs area. Press it, enter the code, and hit Redeem.

Are the long code lists on other sites wrong?

They are dated snapshots, not current lists. Several still show dozens of older strings while missing the codes the official page prints today, so this site copy-cards only the official page and labels older strings as unconfirmed.

Do I need codes to progress?

No. Codes are a head start — the real loop is food XP, stats, class upgrades, and gems from destroyed tanks. Learn it in the beginner guide.
